# HOLYDON CUT

Focused Android video + soundtrack app (Java): import video, play/pause, Sound Finder web search, pick local soundtrack, preview selected audio, optional HOLYDON watermark.

## Build
GitHub Actions workflow builds a debug APK on push. Open Actions and download the artifact after the workflow finishes.

## Scope/limitations
Sound Finder currently searches the web (not a built-in licensed music catalog). This repository is a reconstructed starter source because the previously generated ZIP workspace was not available in the current session. Android compilation/device testing is not yet verified. Export/mixing functionality is still being implemented.
